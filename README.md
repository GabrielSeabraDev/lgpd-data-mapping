# LGPD Data Mapping

A Python learning project for mapping personal data processing activities under Brazil's General Data Protection Law (LGPD).

## About the Project

This project was created as part of my studies in software development, data protection and information security.

The goal is to explore how programming can be used to organize information related to personal data processing activities, connecting legal concepts from the LGPD with technical implementation.

## Current Features

The first version stores a fictional data processing activity containing information such as:

- Process
- Personal data
- Purpose
- Legal basis
- Data sharing
- Retention period

The program then displays the information in a structured format.
